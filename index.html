Ferris Adventure | 2025

👨‍💻 Programmer (Team project)

Mobile Android online multiplayer RPG game

What I did
Online Multiplayer System (Photon Fusion) Built a real-time multiplayer system with Photon Fusion, syncing player position, HP, state, items, and inventory across clients. Used AI tools (Claude) to assist in designing and implementing the networking architecture.
Firebase Login & Authentication System (Unity) Implemented account registration and login using Firebase Authentication, backed by Firebase Realtime Database for persistent player data. Handles the full flow from sign-up to loading/saving player stats, inventory, and progression across sessions. Designed the save/load layer to integrate cleanly with the Photon Fusion networked architecture, preventing client–host data conflicts.
Inventory System (Unity + Firebase) Stores items in a 5x5 grid (25 visible slots out of a maximum of 800 total slots), with a stacking system (items of the same type can be stacked together) and quick-slot consumable use. Saves data to Firebase and reloads it on game entry.
Equipment System Implemented gear equipping with a set-bonus system — wearing a complete armor set grants additional stat bonuses.
Enemy AI System (Multiplayer RPG) Developed the full enemy pipeline from spawning to combat: a 5-state AI state machine (Patrol, Chase, BackOff, Position, Attack) with layered sub-behaviors for natural-feeling movement, a kill-quota stage progression system, and loot drops for items, gold, and EXP.
